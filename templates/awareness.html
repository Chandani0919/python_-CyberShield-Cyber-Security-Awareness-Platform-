01 // ACCOUNT SECURITY

Protect your sign-ins.

  • Use a unique, long password for every account.
  • Store passwords in a trusted password manager.
  • Turn on multifactor authentication, especially for email and financial accounts.
  • Never share passwords or one-time verification codes.

02 // PHISHING DEFENSE

Pause before you click.

  • Be wary of unexpected urgency, threats, or too-good-to-be-true offers.
  • Check the actual sender and domain, not only the display name.
  • Go to a site directly instead of following unexpected links.
  • Verify unusual payment and data requests out-of-band.
OPEN THREAT SCANNER ↗
⟳
03 // DEVICE HYGIENE

Keep your devices ready.

  • Install operating-system and application updates promptly.
  • Use a screen lock and automatic device locking.
  • Keep security protections enabled and back up important files.
  • Install software only from trusted publishers and stores.
◇
04 // DATA & NETWORKS

Protect what you connect to.

  • Share only the personal information an app or service actually needs.
  • Avoid sensitive activity on unknown Wi-Fi; use a trusted VPN if needed.
  • Back up important data and test that you can restore it.
  • Report suspected incidents quickly to the appropriate support team.
⚑
ATTACK SPOTLIGHT

Recognize common warning signs.

PHISHING

Impersonation that tries to steal credentials, data, or money.

SOCIAL ENGINEERING

Manipulation using urgency, trust, authority, or fear.

MALWARE

Harmful software often delivered through untrusted files or downloads.
